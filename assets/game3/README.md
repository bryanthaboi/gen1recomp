Gen 3 bundled glyphs

`lock.svg` is Lucide's `lock` icon (https://github.com/lucide-icons/lucide/tree/f06ac67e33d645c40b8ce19a0419c85c5d7dd751, ISC license, see `../launcher/lucide/LICENSE`).

`lock8.png` (7x7 glyph in an 8x8 cell) is that icon rasterized with rsvg-convert, thresholded to one bit and drawn in the FRLG standard text palette the way the cart's fonts shade: foreground dark gray (98,98,98), shadow light gray (213,213,205) one pixel right, below and diagonal. Background is transparent.

These are the only non-ROM pixels in the Gen 3 UI; the cart has no lock art.
